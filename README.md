# ROS2_창원대학교용

스팩: 뉴클리오 F446re, 라즈베리파이 4, 모터 드라이버(cytron)
센서: YLidar G4, Intel RealSense D415

라즈베리 파이: Ubuntu Server 22.04로 설치
접속방법: ssh ubuntu@raspberrypi.local   /PW: 20081520a


목표1: 미로 속 물체를 인식하고 그래퍼로 잡은 후 다시 원래 자리로 복귀
목표2: 경기장 중앙에 있는 물체를 빠르게 인식하고 빠르게 잡고 물체 뺏기지 않게 하기

현재 환경: VScode, 아두이노 쪽은 Extension PlatformIO 사용할 예정
