# 2D SLAM Implementation Plan

**Goal:** Deliver an encoder-assisted ROS 2 SLAM bringup and hardware-free demo.
**Architecture:** G4 /scan + encoder odom TF feed SLAM Toolbox. A separate synthetic
sensor executable replaces both inputs for development only.

**Spec:** `docs/superpowers/specs/2026-09-08-slam-design.md`
