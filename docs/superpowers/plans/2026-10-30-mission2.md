# 미션2 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** 미션2(빠른 확보 → (3,3)~(7,7) 순환, 보유 상대 모서리 밀기)를 미션1과 분리된 노드로 구현하고 Gazebo 배틀 시뮬레이션으로 검증.
**Architecture:** ROS 없는 판단 함수 `cwu_nav/mission2_logic.py`(pytest) + 상태머신 노드 `cwu_nav/mission2.py`. SLAM 없이
odom + 벽 맞춤으로 경기장 좌표. 시뮬레이션은 `cwu_sim`에 새 world 생성기·심판/상대 노드·launch를 추가하고 기존 `fake_board`·`robot()`을 재사용.
**Spec:** `docs/superpowers/specs/2026-10-30-mission2-design.md`

## Global Constraints

- 미션1 파일(`mission1.py`, `grid.py`, `mission1.yaml`, `maze.py`, `fake_board.py`)은 수정하지 않음 — 다른 세션이 작업 중. import만.
- 경기장 좌표: 원점 중앙, 칸 (i,j) 중심 ((i-5)·0.4, (j-5)·0.4). 출발 = (2,2) 중심, 진행 방향 +x(중앙이 왼쪽).
- 모서리 칸 = |x|>1.4 그리고 |y|>1.4. 고리 = 꼭짓점 (±0.8, ±0.8) 정사각형, 반시계.
- 튜닝값은 전부 `src/cwu_nav/config/mission2.yaml`.
- 보드 인터페이스: `/cmd_vel`, `/base/command`("ARM","7","8","PF0","PF1"), `/base/telemetry`(PSD 6~9, 서보 10~11), `/base/event`.

## Review Focus

- 쥔 채 밀려 엔코더가 미끄러짐 → 벽 맞춤이 위치를 되찾아야 함 (`test_wall_fix_recovers_shift`).
- 벽 근처 상대 로봇 점이 벽 맞춤을 끌어당김 → 중앙값으로 버팀 (`test_wall_fix_ignores_robot_near_wall`).
- 어떤 상태에서든 모서리 칸으로 들어가는 속도 → 0 (`test_corner_guard_*`).
- 정면에 상대가 붙은 채 PSD 근접 → 닫지 않음 (`test_robot_ahead`).
- 상대 보유 판정이 바닥 큐브 앞을 지나는 로봇에 속음 → 시뮬레이션에서 확인.

### Task 1: 판단 함수 `mission2_logic.py`

**Files:** Create `src/cwu_nav/cwu_nav/mission2_logic.py`, Test `src/cwu_nav/test/test_mission2_logic.py`

**Produces:**
- `START = (-1.2, -1.2, 0.0)`
- `in_corner(x, y, margin=0.0) -> bool`
- `corner_guard(pose, v, w, margin, lookahead) -> (v, w)` — 예측 위치가 모서리 영역(여유 포함)으로 더 들어가면 v=0
- `ring_target(pose, half=0.8, lead=0.3) -> (x, y)` — 반시계 정사각형 위 lead 앞 점
- `pursue(pose, target, v_max, k, turn_only_rad) -> (v, w)`
- `wall_fix(points_arena, tol, min_points) -> (dx, dy) | None` — 벽 x,y=±1.8 근처 점의 중앙값 잔차
- `robots(points_arena, wall_margin, gap, min_points, max_extent) -> [(x, y)]`
- `robot_on_bearing(own_xy, bearing, robots, tol) -> (x, y) | None` — 방향선에 가장 가까운 로봇
- `push_plan(own_pose, opp, behind, lateral_tol) -> (target_xy, pushing: bool)`
- `flee_target(own_pose, opp, step, margin) -> (x, y)`
- `robot_ahead(points_base, half_width, reach) -> bool`
